# Face Detection (VGG16 — Keras / TensorFlow)

**Face detection with a dual-head VGG16-based model, trained on augmented images.**
This repository contains a Jupyter Notebook (`code.ipynb`) implementing preprocessing, augmentation, model definition, training, and saving for a face detection pipeline.

---

## Overview

This notebook demonstrates a face detection system built and trained with TensorFlow / Keras. It uses **VGG16** as a convolutional backbone and two separate heads:

1. a **binary classification head** (face/no-face) and
2. a **bounding-box regression head** (4 coordinates: `[x_min, y_min, x_max, y_max]`, normalized).

Data is heavily augmented using **albumentations** and organized into `tf.data` datasets for efficient training.

---

## Features

* **VGG16-based** feature extraction and dual-output **Keras model**
* **Custom bounding-box regression loss** (`localization_loss`) combining coordinate and size errors
* Robust **augmentation pipeline** (albumentations) applied to images and bounding boxes
* `tf.data`-based training pipeline with mapping to outputs `{"class_output", "bbox_output"}`
* Training utilities and TensorBoard callback for monitoring
* Model saved to `facetracker.keras` for later inference or deployment

---

## Model architecture & losses

### Architecture (high-level)

* Input: `Input(shape=(120, 120, 3))`
* Backbone: `VGG16(include_top=False)`
* Shared global pooling from backbone (`GlobalMaxPooling2D`)
* Classification head: `Dense(2048, activation='relu') → Dense(1, activation='sigmoid', name="class_output")`
* Regression head: `Dense(2048, activation='relu') → Dense(4, activation='sigmoid', name="bbox_output")`
* Outputs: dictionary `{"class_output": class_prob, "bbox_output": bbox_normalized}`

### Losses

* `class_output` → `BinaryCrossentropy()`
* `bbox_output` → `localization_loss` (custom):

The `localization_loss` implemented in the notebook computes:

* squared coordinate differences for top-left (x,y) components, summed
* squared differences between widths and heights (pred vs true), summed
* returns `delta_coord + delta_size`

Loss weights used in training: `{"class_output": 0.5, "bbox_output": 1.0}`

## Data format & augmentation

* **Source labels:** The notebook reads bounding boxes from XML label files (Pascal VOC–style parsing shown in the notebook).
* **Augmentation:** Done with `albumentations.Compose` including:

  * `RandomCrop`, `HorizontalFlip`, `ShiftScaleRotate`
  * `RandomBrightnessContrast`, `HueSaturationValue`, `CLAHE`
  * `GaussianBlur`, `MotionBlur`, `CoarseDropout`, etc.
* Augmented images and updated bounding-box annotations are written to an `aug_data` directory in the notebook, and then converted to `tf.data` datasets.
* Bounding boxes are normalized for model output (sigmoid outputs scaled to image size in preprocessing).

---

## Training pipeline

* Datasets are prepared as `tf.data.Dataset.zip((images, labels))`
* Labels are converted to `{"class_output": class_label, "bbox_output": bbox_coords}` with `format_labels` map function
* Datasets are shuffled, batched (batch size = 8), and prefetched
* Optimizer: `Adam(1e-4)`
* Epochs: **5** (as in the notebook; adjust higher for better results)
* Callbacks: `tf.keras.callbacks.TensorBoard(log_dir="logs")`
* Model saved with: `facetracker.save('facetracker.keras')`

## Results & artifacts

> Note: The notebook trains for 5 epochs by default. Increase epochs and/or add more augmentation or data for better generalization.

## Limitations & scope for improvement

This is a solid educational / prototype pipeline. To make it production-ready or higher-performing:

### Model & Loss

* Use **IoU-based losses** (e.g., GIoU/DIoU/CIoU) for better bounding box regression performance.
* Add multi-scale anchor boxes and detection heads like SSD/RetinaNet for better handling of multiple faces and varying scales.
* Replace plain VGG16 heads with small conv heads and use feature pyramids (FPN) for scale robustness.

### Training & Data

* Increase epochs and tune learning-rate schedule (`ReduceLROnPlateau`, cosine annealing).
* Use cross-validation and more labeled data or synthetic augmentation.
* Add class-balancing if negative samples dominate.

### Evaluation

* Implement standard metrics: **mAP** (mean Average Precision) and precision–recall curves.
* Add validation visualizations: overlay predicted boxes vs ground-truth and compute IoU.

### Performance & Deployment

* Convert to **TensorFlow SavedModel -> TFLite / ONNX** for mobile/edge deployment.
* Use model pruning / quantization or TensorRT for low-latency inference.
* Provide a simple Flask / Streamlit demo for browser/web use.

### Robustness

* Add face landmark detection (eyes, nose, mouth) using a secondary head or MTCNN-like cascade for downstream tasks (alignment/recognition).
* Add adversarial/noise robustness and test on varied lighting / occlusion conditions.
